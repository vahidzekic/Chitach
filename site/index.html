Chitach

Besplatan program otvorenog koda za čitanje srpskih elektronskih dokumenata: lične karte, zdravstvene knjižice i saobraćajne dozvole. Za Windows, macOS i Linux.

A free, open-source reader for Serbian smart-card documents: the ID card, the health insurance card and the vehicle registration card. For Windows, macOS and Linux.

Preuzmi najnoviju verzijuDownload the latest version Izvorni kodSource code

MogućnostiFeatures

Lična kartaID card

Svi modeli sa čipom: lični podaci, prebivalište, fotografija i podaci o dokumentu.

All chip models: personal data, address, photo and document details.

Zdravstvena knjižicaHealth insurance card

Podaci o osiguraniku i osiguranju, a „overena do“ jednim klikom sa RFZO servisa.

Insured person and coverage data, with the validity date fetched from RFZO in one click.

Saobraćajna dozvolaVehicle registration

Podaci o vozilu, vlasniku i korisniku, uz proveru parking kazni po tablicama.

Vehicle, owner and user data, plus a parking fines check by plate number.

IzvozExport

PDF kao zvanični obrazac (latinica ili ćirilica), JSON i XLSX, uz automatsko čuvanje.

PDF in the official layout (Latin or Cyrillic), JSON and XLSX, with automatic saving.

ePorezi i potpisePorezi and signing

Smartbox emulacija za prijavu na ePorezi i potpisivanje XML-a kvalifikovanim sertifikatom.

Smartbox emulation for the ePorezi portal and XML signing with qualified certificates.

PrivatnostPrivacy

Podaci sa kartice ne napuštaju vaš računar, osim kada to sami zatražite.

Card data never leaves your computer unless you ask for it.

Politika potpisivanja kodaCode signing policy

Windows izdanja potpisuje besplatna usluga SignPath.io, a sertifikat izdaje SignPath Foundation.

Free code signing for Windows releases is provided by SignPath.io, with a certificate by SignPath Foundation.

  • Autori i recenzenti:Committers and reviewers: Vahid Zekic
  • Odobravanje izdanja:Approvers: Vahid Zekic

Potpisuju se samo fajlovi koje GitHub Actions izgradi iz ovog repozitorijuma za objavljen tag.

Only files built by GitHub Actions from this repository for a published tag are signed.

Privatnost: podaci sa kartica ne napuštaju računar osim kada to korisnik sam zatraži (upit RFZO-u, provera kazni uz izričitu saglasnost). Pri pokretanju program proverava da li postoji nova verzija na GitHub-u; to se isključuje u podešavanjima.

Privacy: card data never leaves the computer unless specifically requested by the user (the RFZO query, the fines check after explicit consent). On start-up the program checks GitHub for a new version; this can be turned off in the settings.
